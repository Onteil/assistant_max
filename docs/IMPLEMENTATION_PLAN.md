# План реализации проекта

## 1. Архитектура, БД (8 ч.)

- Настройка Aiogram 3.x, создание структуры таблиц PostgreSQL (Users, Tickets, Logs) (3 ч.)
- Разработка фабрики клавиатур и системы навигации по меню (Reply/Inline) (3 ч.)
- Проверка корректности соединений БД и базовых редиректов меню (2 ч.)

## 2. Интеграция с API CRM/1С (10 ч.)

- Разработка модуля асинхронных запросов к CRM и обработки JSON-ответов (4 ч.)
- Реализация приема сигналов от CRM и защита эндпоинтов (3 ч.)
- Unit-тесты для обработки ошибок API: таймауты, неверные форматы данных (3 ч.)

## 3. Интерфейс Сметчика (Клиентский блок) (10 ч.)

- Разработка клавиатур и логика валидации данных (4 ч.)
- Разработка личного кабинета (статус подписки, ключи) и кнопок запроса помощи (3 ч.)
- Тестирование сценария регистрации и отправки заявок (Счет/ТП) в CRM (3 ч.)

## 4. Интерфейс Сотрудника (Рабочее место) (12 ч.)

- Реализация карточек входящих заявок с Inline-кнопками управления для персонала (4 ч.)
- Разработка системы сообщений между сотрудником и клиентом (4 ч.)
- Интеграционное тестирование цепочки «Клиент — Бот — Сотрудник — Бот — Клиент» (4 ч.)

## 5. Календарь и Управление временем (8 ч.)

- Логика обработки текстовых команд админа для изменения рабочих интервалов (3 ч.)
- Вывод текущего графика в чат в читаемом текстовом виде (3 ч.)
- Проверка корректности срабатывания логики «Рабочее / Нерабочее время» (2 ч.)

## 6. Фоновые события и Рассылки (8 ч.)

- Обработчики входящих событий от CRM для автоматической отправки опросов (3 ч.)
- Разработка функционала массовых сообщений с кнопками действий (3 ч.)
- Проверка имитации оплаты и срабатывания триггера на NPS через задержку (2 ч.)

## 7. Администрирование и Деплой (9 ч.)

- Команды и UI для назначения ролей сотрудникам: Админ, Менеджер, ТП (4 ч.)
- Настройка окружения и перенос проекта на сервер заказчика (3 ч.)
- Общее приемочное тестирование всей системы (2 ч.)

---

**Итого: 65 часов**
