# 📚 Документация проекта АЙТАТ-Диспетчер

Навигация по документации Telegram-бота для управления счетами, техподдержкой и продлениями.

---

## 📋 Содержание

### 1. [Техническое задание](TECH_SPECIFICATIONS.md)
**Описание:** Полное техническое задание проекта, включающее описание идеи, ролей пользователей, функциональных требований и архитектуры системы.

**Основные разделы:**
- Коротко об идее проекта
- Роли и пользователи (Сметчик, Сотрудник, Администратор)
- Функциональные требования
- Технические требования и архитектура

---

### 2. [Сценарии работы Сметчика (Клиента)](USERS_SCENARIOS.md)
**Описание:** Детальные пользовательские сценарии для основных клиентов системы — сметчиков.

**Основные сценарии:**
- Регистрация нового сметчика
- Запрос счета на продукт
- Обращение в техподдержку
- Управление личными данными
- Оценка качества обслуживания

---

### 3. [Сценарии работы Менеджера/Техподдержки](MANAGER_SCENARIOS.md)
**Описание:** Рабочие процессы для внутренних сотрудников, обрабатывающих заявки клиентов.

**Основные сценарии:**
- Инициализация и рабочее меню
- Обработка входящих заявок
- Коммуникация с клиентами
- Управление статусами обращений
- Работа с очередью задач

---

### 4. [Сценарии работы Администратора](ADMINISTRATOR_SCENARIOS.md)
**Описание:** Функционал для суперпользователей с полным доступом к управлению системой.

**Основные сценарии:**
- Управление сотрудниками (добавление, редактирование, удаление)
- Настройка ролей и прав доступа
- Мониторинг работы системы
- Управление конфигурацией бота
- Доступ к административной панели

---

### 5. [Автоматизация и уведомления](OTHER_SCENARIOS.MD)
**Описание:** Системные сценарии, инициируемые автоматически без участия пользователя.

**Основные сценарии:**
- Автоматическое продление подписки
- Напоминания о сроках действия лицензий
- Системные уведомления
- Интеграция с 1С (вебхуки)
- Автоматическая маршрутизация обращений

## 👥 Роли в системе

- **Сметчик (Клиент)** — основной пользователь, запрашивает счета и поддержку
- **Менеджер** — обрабатывает заявки на счета и коммерческие вопросы
- **Техподдержка** — решает технические проблемы клиентов
- **Администратор** — управляет системой и сотрудниками
