# Документация i-TAT Bot

Актуализировано: 2 августа 2026 года.

Эта папка содержит только действующую техническую документацию. Исторические отчёты, планы реализации и ручные чеклисты не являются частью документации проекта и не должны добавляться в Git.

## С чего начать

- [README проекта](../README.md) — установка, локальный и серверный запуск, переменные окружения, Alembic, восстановление БД и диагностика.
- [Архитектура](architecture.md) — компоненты приложения, структура кода и фоновые задачи.
- [Бизнес-логика](business-logic.md) — типы заявок, рабочие режимы, очереди, эскалации и конфликты ключей.
- [Интеграции](integrations.md) — MAX, i-TAT API, webhooks и правила работы с медиа.
- [Эксплуатация](operations.md) — развёртывание, обновление, проверка состояния и журналы.

## Источники истины

При расхождении документации и конфигурации используйте следующий приоритет:

1. Модели и исполняемый код текущей ветки `main`.
2. Миграции Alembic и `structure.sql`.
3. `.env.example` и файлы из `deployment/`.
4. Документы из этой папки.

Секреты, реальные идентификаторы пользователей и payload диагностических запросов в документацию не добавляются.

## Текущий охват

Основной поддерживаемый пользовательский канал — MAX. Режим запуска задаётся через `BOT_MODE`; Telegram-код остаётся в проекте, но не входит в текущий основной регрессионный контур.

На 2 августа 2026 года код GitHub и production был проверен на ревизии `6967366`. После этого документационные коммиты могут опережать production без изменения исполняемого кода.
